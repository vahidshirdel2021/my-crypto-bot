# نسخه پایدار ربات معامله‌گر

این نسخه بر پایه نسخه اصلی پروژه ساخته شده تا رابط فارسی و کلیدهای قبلی حفظ شوند.

## اصلاحات اصلی

1. کل رابط و متن‌های کاربری اصلی فارسی حفظ شده است.
2. دکمه «شروع اسکن» و «توقف اسکن» از هم جدا شده‌اند و دیگر Toggle نیستند.
3. `/toggle_active` برای سازگاری با نسخه‌های قدیمی همچنان پشتیبانی می‌شود.
4. Telegram `update_id` در SQLite ذخیره می‌شود تا پیام‌ها دوباره اجرا نشوند.
5. در اولین اجرای این نسخه، با `TELEGRAM_SKIP_BACKLOG=true` پیام‌های قدیمی صف یک‌بار نادیده گرفته می‌شوند.
6. برای ورود معامله قفل per-user اضافه شده تا دو اسکن همزمان سفارش تکراری نسازند.
7. هر اسکن یک `scan_generation` دارد؛ بعد از Stop، Taskهای قدیمی اجازه ورود جدید ندارند.
8. هیچ تغییری در نام callbackهای سایر دکمه‌ها داده نشده و `ui.py` از نسخه اصلی حفظ شده است، به‌جز Start/Stop.
9. پیام‌های نمایشی انگلیسی غیرضروری به فارسی برگردانده شده‌اند.
10. تست‌های پایه syntax، کلیدهای Start/Stop، Telegram offset و Stop barrier اضافه شده‌اند.

## نصب

- ابتدا ربات فعلی را متوقف کنید.
- از `trader_bot.sqlite3` نسخه پشتیبان بگیرید.
- فایل‌های این پوشه را جایگزین نسخه قبلی کنید.
- `.env` فعلی خودتان را حفظ کنید و فقط در صورت نیاز `TELEGRAM_SKIP_BACKLOG=true` را اضافه کنید.
- ربات را اجرا کنید.
- پس از اولین اجرای موفق، می‌توانید `TELEGRAM_SKIP_BACKLOG=false` کنید؛ offset ذخیره‌شده در دیتابیس حفظ می‌شود.

## نکته مهم

این نسخه «پایداری رابط و کنترل Start/Stop» را اصلاح می‌کند و بر پایه کد اصلی ساخته شده است؛ قبل از استفاده با سرمایه واقعی، ابتدا PAPER را تست کنید.
