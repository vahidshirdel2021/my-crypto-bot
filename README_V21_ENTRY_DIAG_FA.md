# نسخه V21 — گزارش تشخیصی عدم ورود

این نسخه بر پایه V20 ساخته شده و منطق اصلی معاملات، تحلیل AI و منوی تلگرام را حفظ می‌کند.

## تغییر اصلی
اگر ربات برای مدت مشخصی سیگنال/پوزیشن جدیدی ایجاد نکند، یک گزارش تشخیصی داخل تلگرام ارسال می‌کند.

گزارش شامل:
- مدت زمان بدون ورود
- تعداد نمادهای بررسی‌شده
- تعداد سیگنال‌های معتبر
- تعداد پوزیشن‌های بازشده
- مشکلات احتمالی دریافت داده
- تعداد موارد متوقف‌شده قبل از ورود
- ۵ دلیل اصلی عدم ورود، با شمارش تکرار آن‌ها

گزارش فقط اطلاع‌رسانی است و هیچ تنظیم یا معامله‌ای را تغییر نمی‌دهد.

## لاگ سرور
`ENTRY_DIAG` همچنان برای تمام مراحل ورود ثبت می‌شود؛ از شروع اسکن تا سیگنال، طرح معامله، ارسال سفارش و تأیید ورود.

## زمان گزارش
پیش‌فرض: پس از ۱۰ دقیقه بدون ورود.

برای تغییر:
`NO_ENTRY_REPORT_SECONDS=600`

مثلاً برای ۵ دقیقه:
`NO_ENTRY_REPORT_SECONDS=300`


## کنترل جدید لاگ تشخیصی
در منوی اصلی گزینه «🔍 لاگ تشخیصی ورود» اضافه شده است.
- وضعیت پیش‌فرض: فعال
- امکان روشن/خاموش کردن گزارش تشخیصی تلگرام
- نمایش آخرین تشخیص‌های ثبت‌شده از داخل ربات
- لاگ فنی `ENTRY_DIAG` سمت سرور مستقل از این کلید است و برای مراحل ورود ثبت می‌شود.

## بهبود منوی اصلی
منوی اصلی از حالت خطی خارج و به‌صورت شبکه‌ای/دسته‌بندی‌شده با چیدمان دو ستونه برای استفاده راحت‌تر در موبایل تنظیم شده است.


### امنیت دسترسی
`ALLOWED_CHAT_IDS` در فاز تست اختیاری است. اگر مقداردهی شود، فقط شناسه‌های داخل آن مجاز خواهند بود؛ اگر خالی باشد، دسترسی عمومی برای تست فعال است. برای REAL استفاده از whitelist توصیه می‌شود.
